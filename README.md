- リポジトリ: https://github.com/hishisyu354-commits/zukan-lagoon (公開)

## ユーザー識別(案A: 端末トークン方式)

アカウント登録なしで「誰が投稿したか」と「承認制」を成立させる仕組み:

1. 各端末は初回投稿時に**秘密の乱数トークン**(192bit)を自動生成しlocalStorageに保存。書き込みに毎回添付する
2. サーバー(GAS)のmembersシートが トークン→(表示名・状態) を管理。状態は `owner / approved / pending / blocked`
3. **未知のトークンの初回書き込みは「参加申請(pending)」として自動登録**され、投稿は保存されない。オーナーが「管理」タブで承認すると以後投稿できる
4. 表示名は登録時の自己申告。**承認後の投稿の名前はサーバー側の名簿から付ける**(クライアントの名乗りは登録時しか効かない)
5. オーナーは `setup()` が発行する**オーナーコード**を公開ページの `#/setup` 画面に入力して確定(先着レースなし。機種変時も同じコードで復帰可能)

保証できること/できないこと:
- ○ 承認した端末しか書き込めない ／ ○ 承認後のなりすまし(他人の名前で投稿)は不可(名前はサーバー付与)
- △ 登録時の名前は自己申告なので、承認時に「これ誰?」をLINEグループ等で確認する運用が前提
- △ 端末=人。ブラウザデータ削除・機種変でトークンが消えると再申請→再承認が必要(オーナーはコードで復帰可)
- 閲覧は完全匿名・制限なし。公開JSONにトークンは含めない
- 将来、案B(LINEログイン)に上げる場合もmembersシートはそのまま引き継げる(トークン列の隣にLINE IDを足す拡張)

## 構成

```
閲覧者(誰でも) ──GET──> GASウェブアプリ ──> スプレッドシート(fish/records/comments/points/members)
投稿者(承認済み) ─POST─> 　同上(端末トークンを名簿と突合)
写真 ──────────────────> Driveフォルダ(リンクを知っている人は閲覧可)
フロント: index.html 1枚(GitHub Pages)。CONFIG.GAS_URLが空の間はモックモード(localStorage)
```

削除・修正はスプレッドシート直編集で行う(削除APIを持たない=攻撃面を減らす)。

## 残りのセットアップ(菱沼の手作業はGASだけ)

1. script.google.com → 新規プロジェクト → `gas/Code.gs` を貼る
   (appsscript.json は「プロジェクトの設定 → マニフェスト表示」で差し替え)
2. エディタで `setup()` を1回実行(権限承認) → ログに**シートURL**と**オーナーコード**が出る(コードは誰にも見せない)
3. デプロイ → 新しいデプロイ → ウェブアプリ / **実行ユーザー=自分 / アクセス=全員** → `/exec` URLを控える
4. `/exec` URLをClaudeに渡す(またはindex.htmlのCONFIG.GAS_URLに自分で記入)→ push で本番化
5. 公開ページの `#/setup` (https://…/zukan-lagoon/#/setup) を開き、オーナーコード+表示名を入力 → この端末がオーナーに

メンバーの招待: 公開URLをLINEグループに貼るだけ。各自が初回投稿→「参加申請」→菱沼が「管理」タブで承認。
